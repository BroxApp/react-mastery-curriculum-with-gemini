## 📝 Engineering Rules & Standards

1. **Practical Engineering First:** Every architectural concept must be backed by code and practical implementation.
2. **Clean Commit Standards:** Use Conventional Commits (`feat:`, `fix:`, `docs:`, `refactor:`, `chore:`).
3. **App Router Best Practices:** Default to Server Components; use Client Components only when interactivity (hooks, event listeners) is required.
4. **Backend-Aligned Thinking:** Design frontend data structures and API contracts in close sync with Laravel backend conventions.
